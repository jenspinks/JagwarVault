# JT THEME TRACKER — MASTER STRUCTURE

---

## Usage Rules

When analyzing a song, visual, interview, performance, lyric, or artifact:

- Explicitly name the active theme.
- Identify the triggering line, image, staging element, or dialogue.
- Assign a tier:
  - **Grounded** — explicit in lyric/interview/visual.
  - **Strong Read** — strongly supported interpretive connection.
  - **Resonance** — speculative/esoteric/system-level mapping.
- Flag confidence where appropriate.
- Track:
  - Dominant Pole
  - Transformation Phase
  - Recursion State
  - Threshold State
  - Narrative Voice
  - Temporal Register

The vault is designed as a **symbolic operating grammar**, not merely a symbolism list.

### Provenance Axis — Inherited Substrate vs Internal Architecture
- **A — Internal architecture** (built inside the JT mythos): Lucius, El Roi throat placement, theatrical EPs, loop/circle, algorithm language, mirror recursion, face-paint systems.
- **B — Inherited substrate** (received/reworked from the wider culture): dream mythology, jazz-standard yearning, American-aspiration narratives, stairway/heaven imagery, gospel-uplift structures, romantic-transcendence language.
- Confirmed cases (*Subject to Flooding*): *Dream / Dream* interpolates Johnny Mercer's 1944 "Dream" (Mercer + Sarah Vaughan credited); *Superhuman (Interlude)* samples Charlie Chaplin's *Great Dictator* (1940) closing speech (Chaplin credited); *Precious Time* samples the **pre-vocal banter** of Sarah Vaughan's "Dream" (Live at Mister Kelly's, 1957; Vaughan credited). Credits: [[Sources/Credits/Subject to Flooding]].
- Confirmed cases (*33*): *Soul Is A Star* samples **Joni Mitchell's "Woodstock"** (*Ladies of the Canyon*, 1970; Joni credited). **Joni Mitchell is a confirmed *33* influence** — and the surrounding *Ladies of the Canyon* themes are pervasive enough (Circle Game ↔ The Circle; "The Arrangement" 33rd-floor/consumer ↔ the title + Online/Pay Attention; the album's father motif) to record **Joni Mitchell / *Ladies of the Canyon* as an influence on 33**, `[W]` for the album-wide dialogue. Credits: [[Sources/Credits/33]].
- **Influence-recording rule (clarified per Jen, 2026-05-30):** an influence is recorded as *established* when there is a concrete anchor (a credit, a sample, an annotated/curated source) **plus** corroborating surrounding themes — **a direct "X influenced me" statement from Roy is NOT required.** This is distinct from asserting *intent for a specific interpretive mapping* (that still hedges). Naming the influence ≠ claiming Roy consciously encoded every instance.
- Rule: prefer **mythic emergence** over **intentional encoding** when a symbol predates JT. Symbolic density can arise from Roy *participating in* an older current. Reading survives; its source relocates. Guards against "Roy intentionally encoded everything." See `CONCEPT-InheritedSubstrate`.
