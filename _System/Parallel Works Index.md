# Parallel Works Index

> **What this is.** The vault's **by-external-work axis** — every external work / author / tradition the catalogue **interpolates, samples, names, board-lists, or rhymes with**, in one tiered registry. The structural echo of Roy's own *"Pattern Represented in Movies"* board-list — but disciplined by tier and provenance.
>
> **It is a finding-aid, not a second home.** The analysis lives on the linked pages ([[Brain/Roy Voice/Roy on Influences]] for named figures; `Sources/Reference/` for per-work dossiers; [[_System/Theme Tracker]] for motifs; the song pages). Don't duplicate readings here — point to them.
>
> **The point of §6 (Ruled-out).** Half this session's work was *killing* plausible-but-wrong attributions. Those negatives are recorded once, here, so no future pass re-runs the hunt. **Co-participant ≠ source:** a work sharing a tradition (Harry Potter, Pinocchio) is `[~]`, never evidence of influence.
>
> **Tiers:** `[G]` grounded (credited / artist-named / board-listed-as-fact) · `[W]` strong read · `[~]` resonance (convergence, not influence) · `[?]` pending · **RULED OUT** (tested, failed). *Maintenance: append as new connections are folded; re-date.* Snapshot 2026-06-14.
