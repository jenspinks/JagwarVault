# Drafts — Fold Status

**Why this exists.** External-GPT analyses get *folded* into canon pages but the second step — stamping the draft `folded-to-canon` + adding a provenance backlink — was applied inconsistently. So drafts sat orphaned in `Essays/_drafts/` looking un-integrated when their content was already in canon. This index closes that gap: it's the single at-a-glance answer to *"is this draft folded yet?"*

**Convention to converge on:** when a draft is folded, set its frontmatter `status: folded-to-canon` and add a backlink from the canon page it fed (the pattern [[Essays/_drafts/The Watchers — analysis brief (external review)|Watchers]] + [[Essays/_drafts/Moths to the Flame — analysis brief (external review)|Moths]] already use). This table is the interim ledger until each draft carries its own stamp.
