# Media Index

A catalog of every piece of media stored in `Media/` or referenced via external link. Each entry tracks: source URL, date captured, file location (if local), and the songs/characters/concepts it documents.

---

## Naming Convention

`type-subject-context-date.ext`

Examples:
- `screenshot-roy-tweet-aquarium-2026.png`
- `still-wttc-jester-faceup-2026.png`
- `video-interview4-roy-vs-lucius.mp4` (or external link)
- `flyer-stop-sir-lucius.png`

Lowercase, hyphens not underscores, no spaces. This keeps WordPress migration clean.

---

## How to Add a New Entry

1. Save a local copy of the image/screenshot to the appropriate `Media/[type]/` folder
2. Add an entry to the relevant table below
3. Use Markdown image embed in any vault file: `![alt text](Media/screenshots/filename.png)`
4. If primary source is a URL, add the URL in the table even if local copy exists (X posts get deleted; YouTube videos get pulled)
