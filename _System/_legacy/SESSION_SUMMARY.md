## Interpretation Framework (Mandatory)

Every Wiki page uses three tiers:

1. **Grounded** — observable fact, quotes, credits, release dates, video content
2. **Strong Read** — interpretive moves backed by 2+ public anchors; hedged (*likely, probably, reads as*)
3. **Resonances** — correspondences from any tradition; explicitly attributed; never claims authorial intent

**Open Questions** and **Counterarguments/Alternate Reads** sections are required on concept and character pages (defense against retrospective totalization).

---

## Source Attribution (Critical Rule)

**Public material is citable:**
- Released songs, albums, lyrics
- YouTube theatrical series (Episodes 1-7 with verified URLs in Master Source List)
- Public social media, interviews, podcasts
- Roy's curated public quotes (three Alice Bailey quotes especially)
- Visible iconography (tattoos, face paint, visual symbols in public photos/videos)
- Universal source material (Bible, mythology, Kabbalah, Jung, Bailey, tarot, etc.)

**Private material (Secret Document):**
- Never quote, never paraphrase, never name as source
- Use only as silent interpretive guidance
- If claim cannot stand on public material alone, it cannot go in vault

**Google Docs (NOT citations):**
- Reference libraries only; cite underlying public sources instead
- Lyrics Doc → cite the actual song
- Transcripts → cite the YouTube episode
- Synthesis docs → extract to public anchors or don't use

## Key Analytical Frameworks (From This Session)

### Welcome to the Circus Analysis
The song performs systematic inversion at multiple levels:

**Literal/sensory level:** teeth falling out, voiceless scream, upside-down, spinning, no exit sign
**Symbolic level:** Ring of Fire (Circle weaponized), The Circus (society scaled), Lucius as light-bearer
**Theological level:** Christ-speech forms with predatory content (*"step right up"* vs. *"come unto me"*; *"I'll chew you up"* vs. *"this is my body"*)

**Key connections:** Jonah (consumed and transformed) vs. WTTC (consumed and discarded); Theseus needs Ariadne's thread to exit the Labyrinth (the thread = the feeling that must not be sacrificed)

### The Jacob/Esau Reframing
**Jagwar Twin as twin-motif at the project's foundation:**
- Jacob = heel-grabber (Genesis 25:26); wounded at Peniel; becomes Israel
- Esau = the other half of the same blessing; driven out
- Lucius as Esau (the exiled twin); Roy as Jacob (the wrestling self)
- The Lucius Lullaby arc: can these twins be integrated rather than perpetually warring?

This connects to the Hidden Name reading and the "both need each other" theology rather than hero-vs-villain frame.

### The Thread (Most Important Concept)
- **"The world tied on a string"** (from *The Circle*)
- **"The song hidden inside its wings"** (the song surviving inside the system)
- **Ariadne's thread** (the line needed to exit the Labyrinth)
- **Feeling as the animating principle** (vowel to consonant structure; angels to angles)
- **The Circus's primary function:** severing the thread by making people sacrifice it themselves

If the thread is feeling, and feeling is what allows navigation of the closed system — then *not sacrificing what you can feel* is the core instruction of the entire project.
