## ⚠ TEST RESULTS (Jen, 2026-06-25) — the phrase hypothesis is REFUTED
Jen tried the §A picks. **All the descriptive esoteric phrases FAILED** (`ABYSS IN/OUT`, `I SPEAK/HEAR THE WORD`, `WORLD SOUL`, `LET IT BURN`, `MAN DEVOURS GOD…`, `LEMON THE RABBIT`, `1 KINGS 5:5`, `DAVAR`). **Only `C884` resolved** — to artifact **"Superficial Conclusions"** (room 89), shown **"ALREADY MINTED."** So:
- **Descriptive text written on an artifact ≠ its unlock code.** The code is a *specific curated clue-answer* (Superficial Conclusions' is `SURFACE PERCEPTIONS`, not anything drawn on it) — **not reverse-engineerable from the art alone.** → §A/§D phrase-mining is **out.**
- **The letter+number "cell-codes" ARE a real, valid second code-layer** (`C884`→Superficial Conclusions). Each artifact has one; entering it works even though the artifact's clue-code is a phrase. `C884` was embedded in the *Upload Recipe* as a cross-reference — so artifacts **cite each other's cell-codes.**
- **Revised lead:** the **cell-code system** (ibby's "cells… the pattern") is the only systematic, guessable layer. Master key = the **community Trello** (held every code + the cell map) + the Discord cell-pattern discussion. The phrases below are kept only as a record of the failed approach.
