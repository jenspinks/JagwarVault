# Hall of Mirrors — Room Map (the Trello)

The community's **master map** of the maze, organized into **16 lists = the realms** (From Darkness, Phantoms of the Past, Unseen Things/Concealed Generation, Seeds of Infinity/Childhood, Ways of Growing (Keys to Kingdom), Life-Changing Connections (VI-link), Seen Things/Illumination, Window of Appearance, Time Garden (22:1), Buried Things, Personified Inner Monologue, Genesis Formula, Instructional Information, Hall of Mirrors (not sure where), **Listening Rooms** = audio). Each card = **`ROOM# - Artifact`**. This is the **cell/room-number system** ibby referenced (*"J-763… a different cell"*) — now fully in hand.

## What the map reveals
- **The numbering is the room system.** `51 - Sir Rabbit` confirms Aite_Lyds' "Room 51." So each artifact has a fixed room number 1–147.
- **⚠ CORRECTED (2026-06-26): the 147 are the DISCOVERED rooms, NOT the maze's total.** Jen opened a **new, previously-undiscovered room** with a guessed word — so the maze has **undiscovered rooms beyond these 147**; the community map is a snapshot of what had been found, not the whole thing. *(The earlier "NO truly-undiscovered artifacts / nothing is missing" claim was wrong — don't rely on it.)* Still true: each **mapped** room has a recorded code (e.g. `110 - Gated` → `Gate of the World` — *named* "Gated," not locked), and the gallery's "Undiscovered/Gated" placeholders mean *this viewer* hasn't unlocked them — **but fresh rooms also exist past the map's edge**, and guessing codes can open them → [[Sources/Artifacts/HoM - Code Grammar & Guessing Strategy v2 (2026-06-26)]].
- **Three artifacts weren't in our gallery catalog — now recovered with codes (opened the cards):**
  - **`3 - 33 (The Death of Me)` → code `TT283`** (a song; screenshot attachment 08-11-22).
  - **`6 - Western Woods` → code `Western Wood Dr.`** (a song; card comments hold recovered lyrics: *"i'm older now i find myself like never before… i'm spiraling oh down… you are my soul…"*).
  - **`12 - Creation W_Aubs` → code `C884`** — but C884 already resolves to *Superficial Conclusions* (room 89, minted), so it's a community **duplicate/mislabel**, not a fresh artifact.
  → **Two genuinely-new artifacts to add: enter `TT283` and `Western Wood Dr.`**
- **Card format = the maze graph:** each card = `Code` + `Accessed From` + `Access to Rooms: RIGHT / LEFT` + an attachment (the artifact image). RIGHT/LEFT = Roy's "two paths" — the maze is a left/right binary graph branching from **THE LOBBY**.
- **The Trello is an older snapshot:** it stops at 147 and has **no `Family Portrait`** (gallery #149, unlocked 06-2026) — so the live gallery has a few artifacts newer than the map.
- **Codes are in the card *descriptions*** (not the titles) — pulling those would give the room#→code mapping + any notes on the `Gated` room. Not yet extracted.
