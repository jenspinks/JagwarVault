# HoM Merkle validation — normalization & method (reproducible)

## Validator (authoritative, offline)
- **Leaf formula:** `leaf(code) = keccak256(utf8(lowercase(code)))` (hex, `0x`-prefixed).
- **Membership:** a candidate `code` is VALID for an uncracked room **iff** `leaf(code) ∈ still_open_leaf_hashes` (the 42-leaf set from `HoM Merkle open-leaf targets (42 uncracked rooms) 2026-06-27.json`, Merkle root `0x88f65411…`).
- This catches **all room types** (image / video / audio / MINT) — unlike GCS-existence, which is blind to mint-type rooms (blind-spot XII). GCS + the live `getMintProof` oracle are used only to *confirm + capture* a Merkle hit, never as the primary filter.
- **Live confirm:** `getMintProof?code=<urlenc>` → non-empty `proof` array = valid (reach via `curl --resolve us-central1-jagwar-twin-33.cloudfunctions.net:443:216.239.36.54`, ≤1 req/5s).
- **Capture:** `storage.googleapis.com/jagwar-twin-33.appspot.com/artifacts/0x{leaf}..{ext}` (DOUBLE dot; ext ∈ jpg/png/jpeg/mp4/mp3/m4a/gif/webp).

## Normalization rules (what is / isn't a variant axis)
- **CASE = NO-OP.** The formula lowercases, so `Beth`/`beth`/`BETH`/`Title Case` all collapse to one leaf. Case variants were **excluded** (they cannot change the result). *(The directive listed title/lower/upper as axes; under this formula they are equivalent.)*
- **Apostrophe = SIGNIFICANT.** `father's` (U+0027 straight) ≠ `father’s` (U+2019 curly) ≠ `fathers`. All three forms were tested per seed; only the exact one hits (confirmed: `in my father's shoes` straight-quote = valid, the other two miss).
- **Trailing punctuation = SIGNIFICANT.** `?`/`!`/`.` toggled per seed (e.g. `WHAT IS IT THAT YOU SEEK?` needs the `?`).
- **Separators (real, tested):** space ` `, underscore `_`, hyphen `-`, concat ``, dot `.`, slash `/`, plus `+`, amp `&`, hash `#`, colon `:`, comma `,`, apostrophe `'`. (Separators ARE real — `FATHER_MIRROR`, `RA-LINK` exist.)
- **Separators (transport-form, tested but expected-miss):** `%20`, `%23` URL-encodings. The leaf is over the RAW string; `%23` ≠ `#`. Included only to prove coverage of the "UI-truncation" blind-spot (VIII) — a special-char code is the raw char, not its encoding.

## Generation method
1. Per seed phrase → `variants(seed)` explodes the separator × punctuation × apostrophe matrix (deterministic, in `harness.py`).
2. Knowledge-based seeds (origin-language, Hebrew-letter, architectural-grammar, transformation-operator, exact-quote, body-part-grammar, cipher/special-char) generated by lane solvers, then run through the SAME exploder + validator.
3. Every candidate's `leaf` recorded; hits = `leaf ∈ open set`.

## Coverage discipline
- "Exhausted" is only claimed with: source corpus, generation rules, candidate count, this normalization spec, hash algo, and per-category hit/miss counts (the CSVs below).
- Artifacts emitted: `tested_hashes_local.csv`, `hits.csv`, `known_fills_open.json`, `candidate_count_local.txt`, this file, `misses_summary.md`.
