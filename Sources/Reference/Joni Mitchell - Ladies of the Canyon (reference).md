# Joni Mitchell — *Ladies of the Canyon* (1970) — Lyrics Reference

**External reference substrate** for the **Joni Mitchell ↔ *33* dialogue** (see [[Sources/Credits/33]] §Inherited substrate). **No JT interpretation here** — this file preserves Joni's own lyrics so the vault can ground the cross-references rather than working from memory. Joni lyrics are cited as **public / universal source** (per [[_System/Boundaries]] source rules).

- **Album:** Joni Mitchell, *Ladies of the Canyon*. Reprise Records, 1970. 12 tracks.
- **Why it's here:** Joni Mitchell holds a **writer credit on *33*'s "Soul Is A Star"** (Spotify) — a *grounded* anchor that makes her a **confirmed influence on *33*** (per the influence-recording rule). Jen's read: "the DNA scattered across the whole album." This file is the substrate for that **Strong Read `[W]`** album-wide dialogue. *(The credited element on Soul Is A Star is likely musical/melodic — the lyrics do **not** quote Woodstock verbatim; see [[Sources/Lyrics/Soul Is A Star]].)*

The only **`[~]` leap** is *specific intent for a single mapping* — e.g. that Roy titled the album *33* **because** of Joni's "thirty-third floor." Striking, not documented. Keep it flagged.
